# File Structure

## Server

- `config/servermodpack/server.json` contains sync and hosting settings.
- `config/automodpack/generated.json` is the generated manifest sent to clients.
- The directories in `syncedModFolders` provide mod JARs.
- The paths in `syncedConfigs` provide configuration files.
- `automodpack/.private/` stores server download secrets and TLS credentials.
- `automodpack/cache/` stores file metadata caches.

The server does not read files from `automodpack/host-modpack/`.

## Client

Downloaded mod JARs are installed in `mods/`. Synchronized configuration files are installed at their configured game-directory paths. Each selected modpack stores its `generated.json` manifest under `automodpack/modpacks/<modpack-id>/`. The client uses `automodpack/store/` for downloaded file objects and `automodpack/.private/` for local secrets and trusted certificates.
