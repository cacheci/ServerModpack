# Modpack Creation

The server scans the directories listed in `syncedModFolders` for JARs and the paths listed in `syncedConfigs` for other files. The default mod directories are `mods` and `mods/client_recommended`; both are ordinary scan directories. Both lists are configured in [server.json](../configuration/server-config).

Mod directories are scanned recursively. Each accepted JAR is represented in the manifest with its mod ID, version, SHA-1, size, and client path under `mods/`. JARs without a readable mod ID or version, mods marked server-only in their metadata, and IDs listed in `server-only-mods` are omitted. AutoModpack itself is omitted.

Configuration sources are mapped to the client's `config/` directory. Relative source paths are based on the server working directory; paths beginning with `/` are absolute. Glob patterns and `!` exclusions are supported. A duplicate client destination stops generation with an error.

Run `/automodpack generate` to rebuild `config/automodpack/generated.json`, or enable `generateModpackOnStart` to rebuild it at startup. The client requests this manifest first, then requests any needed files by SHA-1.
