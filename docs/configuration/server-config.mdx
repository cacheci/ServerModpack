# Server Configuration

The server reads `config/servermodpack/server.json` from its working directory. The file is created with defaults when absent.

## Synced content

| Setting | Default | Meaning |
| --- | --- | --- |
| `syncedModFolders` | `["mods", "mods/client_recommended"]` | Directories scanned recursively for mod JARs. Each accepted JAR is sent to the client's `mods/` directory. |
| `server-only-mods` | `[]` | Mod IDs excluded from the client manifest. Mods declaring a server-only environment are also excluded. |
| `syncedConfigs` | `[]` | Files, directories, or glob patterns sent to the client's `config/` directory. Prefix a pattern with `!` to exclude matches. |
| `nonModpackFilesToDelete` | `{}` | Client paths mapped to exact SHA-1 values for files the client may remove. |
| `autoExcludeUnnecessaryFiles` | `true` | Excludes empty, hidden, temporary, disabled, and backup files. |

Paths in `syncedModFolders` and `syncedConfigs` are relative to the server working directory unless they begin with `/`, in which case they are absolute. `syncedConfigs` accepts `*`, `**`, and `?` glob patterns. Files from outside the working directory retain their path below the selected directory when mapped to the client's `config/` directory. Two source files cannot claim the same client path.

Every mod in the manifest has a mod ID, version, and SHA-1. JARs without a readable ID or version are skipped. Mods whose ID, version, and SHA-1 match a JAR in the client's own `mods/` directory are hidden from the selection screen. Other mods are selected initially and can be deselected individually.

The generated manifest is stored at `config/automodpack/generated.json`. It is produced by AutoModpack and should not be edited. The server config and generated manifest are never included in `syncedConfigs`.

## Hosting and connection

| Setting | Default | Meaning |
| --- | --- | --- |
| `modpackHost` | `true` | Enables built-in modpack hosting. |
| `generateModpackOnStart` | `true` | Regenerates the manifest when the server starts. |
| `acceptedLoaders` | Current loader | Loaders accepted during the Minecraft login handshake. |
| `bindAddress` | `""` | Local address for a dedicated listener. |
| `bindPort` | `-1` | Listener port; behavior depends on `connectionMode`. |
| `advertisedEndpointHost` | `""` | Download host sent to clients; empty uses the connected host. |
| `advertisedEndpointPort` | `-1` | Download port sent to clients; `-1` uses the connected port. |
| `connectionMode` | Target dependent | `HOLEPUNCH`, `MAGIC_PACKET`, or `DIRECT`. |
| `disableInternalTLS` | `false` | Expects an external TLS terminator when true. Clients still require TLS. |
| `updateIpsOnEveryStart` | `false` | Refreshes the advertised host on startup. |
| `bandwidthLimit` | `0` | Upload limit in Mbps; zero means unlimited. |
| `validateSecrets` | `true` | Checks per-player download secrets. |
| `secretLifetime` | `336` | Secret lifetime in hours. |
| `selfUpdater` | `false` | Server-only builds do not self-update. |

`HOLEPUNCH` uses a marked Minecraft Login connection. `MAGIC_PACKET` uses AMMH/AMOK before TLS, on the Minecraft port when `bindPort` is `-1` or on a dedicated port otherwise. `DIRECT` expects TLS immediately on a dedicated port, or an external endpoint when `bindPort` is `-1`.

AutoModpack is required on clients joining the server.
